# algoritmowski — portfólio pessoal

Portfólio de Erick Lubawski (@algoritmowski): apresentação, trajetória, projetos e
contato — com uma frente pra atrair clientes (sites, apps, automações de WhatsApp,
consultoria de implementação de IA).

Sucessor do [Portifolio](https://github.com/ErickIgorLubawski/Portifolio) (arquivado) —
esse dependia de CMS externo (Hygraph); este é construído do zero, conteúdo em
Markdown versionado no próprio repo, sem serviço pago.

## Stack
Next.js (App Router) + TypeScript + Tailwind CSS. Deploy gratuito no Vercel
(subdomínio `algoritmowski.vercel.app` até migrar pra domínio próprio).

## Conteúdo-fonte
Os rascunhos de trajetória e os cases de projeto vêm de
`../Algoritimo/Portfolio/Trajetoria.md` e `../Algoritimo/Portfolio/Projetos/`
(pasta de planejamento pessoal, repo separado e privado). Esse repo aqui recebe a
versão final já lapidada pro site.

## Rodando local
```bash
npm run dev
```
Abre em [http://localhost:3000](http://localhost:3000).
